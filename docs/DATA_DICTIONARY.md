# Data dictionary

| Field or concept | Definition | Unit or rule |
| --- | --- | --- |
| outcome | Numeric dependent variable | Default example: life_expectancy |
| base predictors | Required explanatory variables | At least one distinct variable |
| controls | Optional candidate regressors | Unique numeric columns |
| missing values | Dropped jointly over all selected columns | Same sample for every model |

New public reconstruction using synthetic data; institutional research records and unpublished findings excluded.

The default example is synthetic or illustrative. Real-data inputs require their own permissions, definitions and source audit. Missing or infinite values are not evidence of a valid measured zero.
